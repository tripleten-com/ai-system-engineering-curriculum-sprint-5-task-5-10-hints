# Step 3: Prepare for the first Instructor Review

## An earlier note doesn't answer one of the questions

<details><summary>Hint 1</summary>

Does the lesson ask you to fix that note, or to say where it's thin and answer in the overview?

</details>

<details><summary>Hint 2</summary>

For each gap, write the Task, the question, and the answer you'd give now. Where in this Task's note does that list belong?

</details>

## You can't find a pull request number

<details><summary>Hint 1</summary>

Open your repository's pull requests, including closed ones. Which pull request merged each Task's branch into `main`?

</details>

## Your answers read like memories

<details><summary>Hint 1</summary>

For each sentence in your four answers, which note and which Task shows it? If none does, what's the claim resting on?

</details>

## The limits list is short

<details><summary>Hint 1</summary>

Go through every note's **What I'd defend**. Which stand-ins did you use, and what did each one stop you from seeing?

</details>
